Drawesome 3

Drawesome 3  is a slideshow application you can use right next to on your digital drawing tablet

Or you can learn more about Drawesome   by clicking here

  • I have decided to make Drawesome 3 free for artists!

    Not tested on Linux Ubuntu, please let me know if you run into any issues by contacting 📧 me here






Just select a mp4, webm, or ogg video file from your computer and you are good to start your slideshow   Drawesome 3   works with the following image file types: .png, .jpg, .jpeg, .jfif, .webp, or .gif using file types other than the one's listed will not show up in the slideshow. The slideshow screen will take up a small area of your screen, or more if you want to show larger sized images. This application does not connect to the internet in any way, so you can practice without Wi-Fi or internet.



Drawesome 3   does not automatically update, so check here for future updates, when I release bug 🐛 fixes.
